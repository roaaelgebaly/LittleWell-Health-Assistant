# Medical RAG App

A child-health medical RAG assistant built with:

- Python + LangGraph backend
- FastAPI API layer
- React + Vite frontend
- ChromaDB semantic retrieval
- Groq-based classification and generation

## Project structure

- `api.py` — FastAPI backend for the app
- `app.py` — Streamlit prototype/app shell
- `graph.py` — LangGraph workflow
- `nodes.py` — classification, retrieval, generation, verification, safety nodes
- `state.py` — internal graph state and structured response model
- `prompts.py` — all prompt templates and safety messaging
- `config.py` — configuration and model setup
- `frontend/` — React frontend
- `chroma_db/` — vector database
- `extracted/` — source documents used for retrieval

## Requirements

### Python

Use Python 3.10+.

### Node.js

Use Node.js 18+.

### Environment variables

Create a `.env` file in the project root with:

```bash
GROQ_API_KEY=your_groq_key_here
```

If you are using any other environment-specific config, keep it in the same `.env` file.

## 1) Create and activate the virtual environment

From the project root:

```bash
python -m venv venv
```

Windows PowerShell:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
.\venv\Scripts\Activate.ps1
```

Then install dependencies:

```bash
pip install -r requirements.txt
```

## 2) Start the FastAPI backend

From the project root:

```bash
python -m uvicorn api:app --host 0.0.0.0 --port 8000 --reload
```

The API will be available at:

- http://localhost:8000/health
- http://localhost:8000/chat

## 3) Start the React frontend

Open a second terminal, then run:

```bash
cd frontend
npm install
npm run dev -- --host 0.0.0.0
```

The frontend will be available at:

- http://localhost:5173

## 4) Example backend request

```bash
curl -X POST http://localhost:8000/chat \
  -H "Content-Type: application/json" \
  -d '{"question":"How can I recognize if my child\'s asthma is flaring up?"}'
```

## 5) Frontend usage

Open the frontend in the browser and ask a question such as:

- How can I recognize if my child's asthma is flaring up?
- What are the signs of dehydration in children?
- What should I give my child?

The app will:

- send the question to the FastAPI backend
- run classification + retrieval + generation + verification
- show a clean user-facing response
- include a developer/debug panel with retrieval and structured output information

## 6) Clarification flow

If the classifier decides the question is ambiguous, the backend returns a clarification prompt. The frontend should then send the user reply back using the same thread ID.

The backend handles this through the existing LangGraph interrupt/Command(resume=...) flow.

## 7) Troubleshooting

### FastAPI not starting

Check that:

- your virtual environment is active
- `GROQ_API_KEY` is set in `.env`
- dependencies were installed with `pip install -r requirements.txt`

### React frontend cannot connect to backend

Check that the backend is running on port 8000 and that the frontend is pointing to the correct API URL.

In `frontend/src/App.jsx` the API URL is currently:

```js
const API_URL = 'http://localhost:8000/chat'
```

### Missing Python dependencies

Run:

```bash
pip install -r requirements.txt
```

### Missing npm dependencies

Run:

```bash
cd frontend
npm install
```

## 8) Notes on architecture

This project intentionally keeps the internal RAG pipeline intact:

- classification
- retrieval
- generation
- verification
- safety redirect

The UI is only a presentation layer on top of that structured backend workflow. The user-facing response is drawn from the structured result generated by the graph, not from a second formatting LLM step.
